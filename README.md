# 远驱 PRO · ND72450 BLE 遥测验证版

这是面向 iPhone 的 HTTPS/PWA 网页工程。当前阶段只实现真实 BLE 连接与已知遥测帧的校验/解码，不伪造数据，也不发送参数写入、复位或刷机命令。

## 目标设备
- 南京远驱 ND72450
- BLE 名称前缀：YuanQu / yuanqu
- 已知 GATT：Service FFE0，Characteristic FFEC
- 遥测帧：16 字节；支持已知 legacy SUM 与新格式 CRC16 校验
- 已解码字段：电压、线电流、RPM、相电流、MOS/电机温度、SOC、油门电压、极对数、调制比、弱磁状态、刹车、故障位图

## iPhone 使用
1. 在 iPhone 安装 Bluefy（支持 Web Bluetooth 的浏览器）。
2. 打开 GitHub Pages HTTPS 地址。
3. 点击“连接 YuanQu 蓝牙”，选择你的控制器。
4. 页面收到有效通知帧后才会填入真实数据；未收到的字段保持 --。

iOS Safari 原生不支持 Web Bluetooth，因此不要用 Safari 普通模式测试。

## 参数读写状态
参数批量读取、单项写入、登录/绑定、保存/恢复暂未实现。虽然社区有部分远驱命令格式与 CAN 参数资料，但不同固件/型号的地址、数据长度、登录状态和写入确认必须针对本机验证。不得把遥测协议等同于参数写入协议。

## 完成完整参数读写所需材料
请在原版远驱 App 中对同一台控制器做一次参数通信记录，至少包括：
1. 连接并登录/绑定；
2. 进入参数页，执行一次“读取/刷新”；
3. 只改一个无风险、可恢复的显示类参数（不要改电流、转速、弱磁、保护等动力参数），保存；
4. 再次读取该参数，确认写入后的返回数据。

导出 BLE HCI/btsnoop 记录或由 Android BLE 调试工具记录 GATT 写入/通知。记录需包含 UUID、写入字节、通知字节、时间顺序。敏感密码/手机号请先遮盖。仅凭设备名 YuanQu 无法推导写入帧。

## 安全
- 当前网页没有任何控制器参数写入功能。
- 不要在车辆驱动使能、车轮着地或行驶中调试。
- 写入功能只有在确认 ND72450 固件协议、字段地址、缩放、范围、校验和回读机制后才会启用。
